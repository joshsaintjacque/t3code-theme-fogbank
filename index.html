Notes on the coast, in Iowan Old Style.

Headings use the system serif (Iowan Old Style, Palatino, Georgia) for a printed-chart feel. Everything else keeps the app's own sans and mono, so code stays exactly as crisp as you expect.

  • Indigo is the only saturated colour on screen: send, focus, links.
  • Amber belongs to the lamp: the beam and the glints appear only while something is happening, and the lamp blooms once when a turn ends.
  • Fog art always sits behind a clear reading column, never behind text.
  • All text pairs clear WCAG AA; body text is 11.5:1 on the canvas.
